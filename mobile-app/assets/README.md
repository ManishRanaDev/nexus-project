# Assets Required

Before running the app, you need to add these image files to this directory:

1. **icon.png** - App icon (1024x1024px)
2. **splash.png** - Splash screen (1242x2436px)
3. **adaptive-icon.png** - Android adaptive icon (1024x1024px)
4. **notification-icon.png** - Notification icon (96x96px, transparent background)

## Quick Setup (Use Default React Native Icons)

For testing, you can use Expo's default icons:
1. Run `expo start`
2. Expo will generate default icons automatically

## Or Create Your Own:

Use any image editor to create a simple icon with:
- Purple/blue gradient background (#667eea)
- "N" or "Nexus" text in white
- Save as PNG files in the sizes listed above
